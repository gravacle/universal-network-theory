Four different assurances must not be conflated:

1. **Byte custody:** Git identities and SHA-256 establish which exact files
   support a statement, not that the statement is scientifically true.
2. **Executable consistency:** a validator can establish arithmetic, declared
   invariants, or faithful reporting. Its coverage and missing dependencies
   determine what its PASS means.
3. **Independent reconstruction:** separately implemented target/hostile
   routes reduce common implementation risk. They are project-internal unless
   external independent authorship is actually documented; they are not
   automatically independent experimental corroboration or peer review.
4. **Physical inference:** a result reaches only its declared construction,
   quantifiers, assumptions, and numerical guards. Formal closure and model
   agreement do not by themselves establish that nature realizes the model.
