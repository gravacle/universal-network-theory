## Reproduce the bounded checks

The verifier uses the host's Python 3 interpreter and NumPy installation. The
capsule deliberately does not embed a platform-specific interpreter or wheel.

From an extracted capsule root:

```bash
python3 -B tools/verify_extracted_capsule.py .
```

The extracted verifier checks archive-local navigation, exact hashes for the
record theorem, internal hostile audit, and sealed z1 packet, reruns the native ARGER
reconstruction, verifies the L08/L10 cache extraction, authenticates the
full-workflow L12 strict-lineage result and custody, authenticates the proof-packet layouts,
executes the portable alpha scope gate and algebraic witness/DAG regression,
and runs the focused relational URM validator against an authenticated public
projection of its exact repository dependency closure. The only projected
positions are the two path-neutral L08/L10 cache manifests and the adapter
that authenticates them back to their raw source-manifest hashes; the archive
also retains and authenticates the byte-exact relational model source. The repository Alpha URM
integration result is documentary/Git-only because its complete aggregate
runner is outside this focused closure. The verifier does not execute excluded
cloud-run history or advertise broader validators whose complete dependency
closures are not in the capsule.

For the secondary strict common-lineage diagnostic, the capsule recomputes
`L = 8` and `L = 10`. The `L = 12` Target/Hostile values are authenticated
outputs of the full repository workflow. A 2026-09-18 review rerun reproduced
both values and generated a report byte-identical to the sealed report. The
complete audited workspace is approximately 59 GB; the minimum runnable
`L = 12` reconstruction set alone is 13,485,786,130 bytes (12.559617 GiB).
This focused archive preserves the method, result, and cryptographic custody
without duplicating those bulk generated input arrays.

The native ARGER Gate evidence validator can also be run directly:

```bash
python3 -B DEVELOPMENT_R_ARGER_GATE_V001/arger_gate.py
python3 -B DEVELOPMENT_R_ARGER_GATE_V001/test_arger_gate.py
```

From the repository root, preparation checks are:

```bash

python3 -B -m unittest discover -s publication/zenodo_reproduction_v001 -p 'test_*.py'
```

Those two preparation commands are for a source-repository checkout. From an
extracted capsule, use `python3 -B tools/verify_extracted_capsule.py .`; do not
run blanket test discovery against repository-only test modules whose source
layout is intentionally absent.

The builder selects only explicit manifest paths, rejects unsafe archive
paths, verifies hash-pinned closures, excludes private path-bearing research
envelopes, and builds a deterministic archive only when explicitly asked.

still requires human-supplied values for the immutable Git tag and commit,

archive containing its placeholders.

capsule is the smaller proof-guided reproduction surface.

**Publication → Preprint**. The title “Universal Network Theory Major Proof
Index” belongs to the internal navigation document, not to the theory itself.
That PDF is the primary publication file and default preview; the deterministic
