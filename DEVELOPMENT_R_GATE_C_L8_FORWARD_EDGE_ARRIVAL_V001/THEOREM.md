zero, background writes at nodes `1..N`, target node four, authenticated
`W_R=1/2` write map, and common phase. Retain every owner-once edge, including
the wrap-around path.

Define the directed forward-sector contrast

\[
 \delta J_{3\to4}^{(N)}(t)=
 J_{3\to4}^{\mathrm{background}+\mathrm{probe}}(t)-
 J_{3\to4}^{\mathrm{background}}(t).
\]

Define `tau_fwd(N)` as the first positive local maximum of this contrast above
`1e-8` on `0<t<=2*pi`, with the fixed three-point parabolic rule. Record its
peak value and the ensemble contrast in node-four occupation at the same
time.

## Claim boundary

The observable selects the signed inflow through edge `3 -> 4`; it does not
delete the counter-clockwise route, identify an individual packet, or prove
which earlier route generated a contribution. A monotone result would be a
finite operational forward-edge delay under this protocol only. It would not
be metric strain, gravitational time dilation, Shapiro delay, or gravity.

The numerical table and its monotonicity status remain empirical and pending
independent hostile audit.
