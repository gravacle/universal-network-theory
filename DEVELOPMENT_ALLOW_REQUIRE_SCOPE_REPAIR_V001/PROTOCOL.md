# Allow / Require / Select scope-repair protocol

## Objective

Reconcile the early `G-3` / `D-4` allow-require doctrine with the later sealed
`ALLOW / REQUIRE / SELECT` ladder before any algebraic-scaling result is
interpreted.  The repair is semantic, formal, and dependency-scoped.  It does
not change a historical measurement, import a gravitational algebra, or claim
continuum emergence.

## Objects that must remain distinct

The repair must define and type, at minimum:

1. a parent/carrier specification `P`;
2. its state space `H_P` and admissible subset or constraint kernel `A_P`;
3. an admissibility predicate `ALLOW_P(x)`;
4. a conditional universal or singleton statement `REQUIRE`;
5. an occupancy/state `rho`;
6. an internal dynamical map `D_P`;
7. a selector statement `SELECT_parent`;
8. constraint generators `C_a`; and
9. characteristic projectors `Pi_a`, only when a predicate defines a linear
   subspace and the operator representation is specified.

No predicate is converted into an operator by notation alone.  No projector
commutator is called a constraint-generator algebra without an exact map.

## Candidate scoped theorem

The target repair must prove or formally derive the following bounded content:

> Within one frozen parent/fiber, internal dynamics changes occupancy in the
> admitted space and does not change the definition of that parent's
> permissions.  An enlarged parent may contain a dynamical carrier label and
> fibered admitted spaces; evolution in that enlarged parent can select or
> change the effective realized fiber without contradicting the frozen-parent
> statement.

The later sealed alpha theorem is the governing precedent:
`LANE_RFT_ALPHA_SECTOR_INHERITANCE_V001/THEOREM.md`, section 8.  In that
ladder, finite recordhood `ALLOW`s an admissible set, host ancestry conditionally
`REQUIRE`s one member for every same-sector realization, a complete-universe
`REQUIRE` is a singleton theorem, and dynamical `SELECT` is independent.

## Canonical-edit rule

Prior historical prose is not silently rewritten.  The integration produces:

1. one target theorem;
2. one provenance/dependency table;
3. a dated erratum/scope note;
4. minimal live-ledger and continuation changes; and
5. explicit pointers from current governing documents to the repair.

Generated or sealed documents are changed only through their own registered
update mechanism or by an append-only correction pointer.  Unrelated dirty
work is excluded with explicit `git add` paths.

## Hostile audit gates

The independent audit method must be frozen before the integrated target
theorem is inspected.  It must fail closed if:

- a live dependency is omitted;
- predicate, projector, generator, occupancy, or dynamics are conflated;
- the fixed-parent statement is promoted to a ban on enlarged-parent dynamics;
- the ADM/Dirac citation is used to claim all gravitational equations are only
  static admissibility statements;
- historical evidence is silently rewritten;
- an exact zero projector commutator is labeled a spacetime-algebra anomaly;
- a record-level classical behavior is imposed as a microscopic criterion; or
- empirical finite-size scaling is promoted to a continuum or gravity proof.

## Downstream gate

Only a hostile-audited scope repair authorizes the centerline `rho=1/4`
Krylov run.  That run may test whether a `z=1` finite-size family is compatible
with the sealed L4--L8 values; it cannot establish exact `z=1` from finite
numerics.  Failure halts only the proposed algebraic-scaling route.

**Proved inputs:** exact repository history, existing sealed finite results,
and exact algebraic identities explicitly replayed.

**Adopted:** the type vocabulary, dependency dispositions, and audit gates.

**Conditional:** enlarged-parent/fiber applications until a physical enlarged
parent is constructed.

**Open:** selection of a realized parent, continuum symmetry, anomaly limit,
universal coupling, emergence, and gravity.
