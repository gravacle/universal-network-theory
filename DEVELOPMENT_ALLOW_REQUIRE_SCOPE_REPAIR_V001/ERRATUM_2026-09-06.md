## Governing replacement

`ALLOW_P(v=a)` means membership in the attainable set of a declared parent.
`REQUIRE_P(phi)` means a universal statement over that parent's nonempty
admissible set; for a numerical value it is a singleton theorem.
`SELECT_{P,D,mu_0}(v=a)` is a separately supplied dynamical explanation of
which allowed occupancy becomes actual.  None of these English labels creates
an operator.

Within a frozen parent and fixed admissible fiber, admissibility-preserving
internal dynamics changes occupancy and does not redefine that parent's
permissions.  A complete enlarged parent may instead carry a dynamical
carrier label, inter-fiber maps, and a global conservation/accounting law.  It
can then change the effective fiber seen by a subsystem while its own global
admissible space stays fixed.  This is a logical reopening, not evidence that
the program has constructed such a physical parent.
