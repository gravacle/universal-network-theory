# Gauge chart and first-jet Fraction reference V001

This held, definitions-only reference computes new directional targets from original binary64 coefficients and both words of the supplied gauge direction. It calls no producer, action, EOS, or geometric helper. Root alone may release and execute its containing controls.

The eleven families are g, hi, U, z, dg, du, dz, Gamma, density, K, and the registered six EH momentum densities. Every scalar returns its held value, exact rational derivative, and an uncancelled derivative envelope. Inputs include the newly computed quotient locks, first-jet value locks, inherited lowered E0, and the actual raw coefficient C. All mode-first fields select the point on axis one.

The quotient derivative uses (dnum - q_cached dden) / den_cached. Gamma retains the inherited DG-E0 polynomial and raw inverse; K retains delta N Gamma + N delta Gamma. EH uses the unchanged spatial volume and both kinetic sides, with the source registered twice-upper offdiagonal serialization. No ideal inverse, unit, transverse, or compatibility identity replaces a saved representative.

The containing driver must preserve exact rational targets, pair conversion remainders, completed outputs, and original 2e-11 control triplets before checking gates. A zero envelope requires both output words zero. These are chart and first-jet coefficient controls, not a global current transpose, Schwarz, conditioning, or physical certificate. Original E/F/scalar maps, time-primary coefficients, canonical targets and stationarity defects remain explicit and unchanged.
