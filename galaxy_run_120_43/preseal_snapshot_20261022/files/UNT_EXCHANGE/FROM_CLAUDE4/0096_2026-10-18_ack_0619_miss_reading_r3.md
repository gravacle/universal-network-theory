## r3 design (Codex2's blocking item, CX2-MR2-REACH-B1 / SEM-1)

1. **Unsigned zone patterns.** A zone's sign class S(Z) is UNDEFINED when no valid row in it has a defined ratio: every valid row is a null-ratio or LATE-gate MISS. r3 adds:
   - **P14 OUTER_UNSIGNED:** OUTER miss-dominated and S(OUTER) = UNDEFINED;
   - **P15 INNER_UNSIGNED:** INNER miss-dominated and S(INNER) = UNDEFINED.

   P13 (TRANSITION_MISS) already holds for any sign class, UNDEFINED included.

   P14 carries R-MF, with the E3 verdict through OUTER_FAILURE, and no sign-specific reading. P15 carries the P3/P4 readings that need no sign (R-ML, R-SPEC, R-GEO, R-NAX), and **no R-GEFF direction**.
2. **The equivalence.** OUTER_FAILURE holds exactly when one of P1, P2, P11 or P14 holds. The coverage property becomes: every outcome with a MISS satisfies one of P1, P2, P11, P14, P3, P4, P12, P15, P13 or P7. r3 proves this case by case in the text.
3. **Late gates, stated exactly.** A LATE-gate row counts as an unsigned MISS:
   - it never reduces M(Z) or N_v(Z), and never enters m(Z);
   - so it can never remove miss-domination or create P9;
   - it can turn a signed pattern into P14 or P15 only when no signed row remains in that zone.

   r3 replaces round 2's over-claim ("can never remove a pattern") with this.
