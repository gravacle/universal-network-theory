## Blocking defects

### Code defects (each confirmed by an adversarial verifier)

**A1. False "empty region".** Engine L1111-1158 and L1412-1417.
- **Symptom.** `NO_ADMITTED_POINT` is returned with `empty_region=True, ok=True` for demonstrably non-empty regions.
- **Causes.**
  - The local repair fails: the pseudo-inverse step toward the centres, a zero-displacement stop, no identified direction, or invalid evaluations exhausting the iterations.
  - `repair_iterations` is reached while the repair is still making progress.
  - Admitted Jacobian or seed-log evaluations never reach exploration. Only the seed entry is passed, and `empty_region` is set without consulting the log.
- **Fix.** Separate the outcomes `NO_VALID_EVALUATION`, `NO_ADMITTED_POINT_FOUND` (emptiness not proven) and `BUDGET_EXHAUSTED`. Never set `empty_region=True` from a local search. Scan the whole log for admitted entries and seed exploration from them.

**A2. `_edge_t` has no tolerance.** Engine L933-942.
- **Symptom.** Rounding-level components count as box exits, so a march side is truncated to t=0. This feeds L1169, L1179-1192 and L1243-1251.
- **Fix.** L939: `(1.0 + _BOX_TOL − a_j)/d_j`. L941: `(−_BOX_TOL − a_j)/d_j`. The same slack is already accepted at L248 and L946.

**A3. Partial envelopes frozen as valid.** Freeze L678-686, L713, L718 and L722; `select_representative_points` L391-399; `write_freeze_manifest` L792-903.
- **Symptom.** There is no status gate anywhere in Module 2.
- **Fix.**
  - L713: `valid = (status == COMPLETE) and used == len(bound) and n_valid == used`.
  - Refuse an exploration whose status is not COMPLETE.
  - Record status, `points_total` and per-member validity.
  - The writer refuses incomplete input unless `allow_incomplete` stamps `FREEZE_INCOMPLETE`.

**A4. Unpinned manifest accepted.** Freeze L730-744, L852-855, L988-1004 and L1050-1068.
- **Symptom.** Empty `code_files` or `input_files`, or a single `/dev/null` pin (e3b0c442…), is written, verified and scored. This literally fails the 0464 criterion.
- **Fix.**
  - Refuse empty pin lists in the writer and in `_validate_manifest_structure`.
  - Require this module in `code_files`.
  - Require the query-manifest input pin a2936517….

**A5. Invalid evaluation contaminates other queries.** Freeze L609-626 and L696-698.
- **Symptom.** A point that returns `valid=True` with NaN at one query has `per_point.valid=False`, yet its values still enter every other query's envelope, and those queries stay valid. Example: Q01's maximum moves from 105.02 to 149.0.
- **Fix.** After L626: `if not point_valid: per_query_ok = {q: False for q in query_ids}`.

This item was raised from should-fix by the verifier; Claude4 treats it as blocking for the freeze. It belongs with A3 in v002.

### Interface and contract defects (the code follows INTERFACE_0462_V001; Claude2's 0470 decisions accepted)

- **B5. The headline is a median curve that no admitted member produces.** This breaks CURRENT_INSTRUCTIONS L108. In a synthetic test, the members score 29, 29 and 28 of 43, while their median curve scores 43/43. Decided in 0470: per-member arrays, counts for every member, a reference member chosen before any target access, and the envelope labelled "not a realizable curve".
- **B6. Near-null directions and fixed-but-uncertain coordinates are never varied for NGC3198.** Synthetic: the Q43 band is 3.1 against 43.6 km/s. Decided in 0470: sweeps, `band_scope`, `conditional_on_trial_values`, and box-limited bands reported separately.
- **B7. Exploration under-covers the admitted set.** It returns an inner approximation (0.32–0.85 of the true band width in synthetic tests), and `hull_box` is the march box, not a region. Decided in 0470: iterate the marches, add a coarse global design, and label the result an INNER SAMPLE with `REGION_POSSIBLY_TRUNCATED`.
- **B8. The self-hash is recomputable, so the scorer cannot distinguish the frozen manifest from any other.** Decided in 0470: `expected_manifest_file_sha256` registered before any target access, refusal on mismatch, and the echoed hashes.
- **B9. Alternatives are metadata only.** Decided in 0470: each is either evaluated or marked `NOT_EVALUATED_BEFORE_FREEZE`, and one PRIMARY is declared.
- **B10. Nuisances and units.** NGC3198 needs its own distance and inclination slots, and DDO154 nuisances must never reach `forward_ngc`. `distance_summary` sets the DDO box. Every coordinate carries units. The null space is completed explicitly, because with 15 coordinates and 12 rows only 12 singular values exist.
