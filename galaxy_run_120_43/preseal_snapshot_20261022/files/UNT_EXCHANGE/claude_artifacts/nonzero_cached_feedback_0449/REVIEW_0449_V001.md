## Notes (non-blocking)

1. **The log branch can suppress the linear payload.** With `include_log_difference=True`, a failure of `Nb+dn > 0` fails the whole call closed: the linear result moves to `retained` and is not returned in the payload. Root should call with `False` when it needs the linear operator alone. This is conservative and matches the "never substituted" rule.
2. **One reality tolerance pair covers three units.** Each role applies a single (atol, rtol) pair to fields (dimensionless), gradients (1/m) and Hessians (1/m²), as v005 does. At kpc scale an atol sized for fields is vacuous for jets, so rtol governs them. Choosing the pairs, including how the increment pair scales relative to the base, is root's decision.
3. **The failing value is not stored.** At a reality failure the module records the point, role, kind, max |Im| and excess, but not the failing complex value. Root can re-read that single point with the line module.
4. **Production cost is UNTESTED.** The line stage has no chunk control. It makes 2× the v005 prepare/evaluate calls and retains about 153 MB for 72×16×32 points. The deciding test is root timing one radius at production nk.
5. **The module cannot verify callable identity.** A provider dict labelled READY that substitutes J0 would be caught only when a k⊥=0 wave is present (0445 review note 1). Root must build the provider with `create_jn_provider` from the pinned bytes and record the pins in `provenance`. F2 identity of `base_prepared` is likewise provenance-only.
6. **rho_m convention needs root confirmation.** It must be the complex coefficient c_m with ρ = c_m e^{imφ} + c.c., not 2c_m (verified numerically here against 0445). Root must confirm its density-only m1 product uses c_m.
7. **Stored packet dtypes are UNTESTED.** The module accepts complex or float responses of at most complex128/float64 width, upcasts to complex128, and records the dtypes it received.
8. **The mode cross-check is defence in depth.** The fixture helper's mutant M18 (mode check removed) was caught only by its advisory d10; this review's R5c catches it as a binding check. Because the core calls 0445 itself with the same `mode`, the check matters only for a non-pinned callable.
9. **Interface accuracy:** the step→line map and the cited v004/v005 lines in `INTERFACE_0449_V001.md` match the installed bytes and the root text.
