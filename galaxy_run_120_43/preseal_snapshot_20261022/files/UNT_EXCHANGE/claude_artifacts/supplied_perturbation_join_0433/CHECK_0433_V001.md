## Notes (non-blocking)

1. **The axisymmetry tolerance is a new caller key.** It is `base_fields['axisymmetry_phi_variation_rtol']`, tested directly as `max|f - f[:,0,:]|/max|f|` for rho0, K0, P0, Omega and Phi0. It is not root's `base_axisymmetry_rtol`, which is a dphi ratio with different semantics.
   - A root base_fields dict as root passes it today (six arrays) fails closed at input_validation with zero callbacks until root adds the key.
   - This is recorded correctly as missing interface fact 1.
   - The direct test catches Nyquist content that a Nyquist-zeroing partial_phi misses. I confirmed this independently.
2. **Phi0 is gated as axisymmetric.** This is stricter than 0427, which gated rho0, K0, P0 and Omega. It is consistent with the root docstring ("Phi0 is m0 reference only") and is recorded as fact 2.
3. **An ungated report can block the callback.** The ungated polytrope and dphi-ratio reports, and the response-independent residual pieces (r0, continuity, entropy, EOS), are evaluated before the callback.
   - A finite input that overflows there fails closed with zero callbacks. Probe: subnormal P0 = 1e-310 gave `floating_point` with count 0.
   - An overflow inside the Euler sums happens after the callback, and the response is retained (probe confirmed).
   - The author discloses this in the limitations. It does not violate 0433, because no callback output exists to retain, but it does let an ungated report block the callback.
4. **`gamma > 0` is required but not listed.** It is a validation choice that 0433 does not state. It appears in the INTERFACE API table but not among the §4 missing interface facts.
5. **Bitwise declared-vs-recomputed imaginary norms.** The check is exact for root's in-process callback. Any transport that perturbs the declared norms fails closed, which is the safe direction.
6. **Retention by identity.** The response arrays stay mutable by the caller. This is disclosed.
7. **Scope.** The 0144 ack and 0145 completion files that 0433 requests are outside both the author and checker scope here, and were not written.
