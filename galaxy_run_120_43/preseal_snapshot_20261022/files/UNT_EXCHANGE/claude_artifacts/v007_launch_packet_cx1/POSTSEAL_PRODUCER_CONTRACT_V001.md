# Post-seal producer contracts — 0599 / A88

All entry points require the existing independently pinned root admission. No pre-seal exception, no solver, and exclusive new outputs. Root alone executes on production. Input JSON rejects duplicate keys and nonfinite literals; every read reference is {path,sha256}, checked from bytes and checked again before publication. Final records carry producer, manifest, input and root admission pins. Outputs under protected or marked run paths are refused.

`postseal_records_cx1v006.py MODE MANIFEST OUTPUT` supports MT, I1T and FLAG_RULINGS. Manifest `runs` maps every one of the ten registered T labels (plus optional registered T RPAIR keys) to its result.json byte reference. Every result must be COMPLETED DDO154, use the sealed driver, have a matching finish.json, and have a distinct path. This writer requires all ten base results even for FLAG_RULINGS.

MT reads the actual pinned route-A attempt result/uv_tail, cross-checks its driver summary, and exports M_T_accepted and flags. Strictly greater than 0.25 means FAIL/TAIL_SOURCE_UNDERCONVERGED; equality passes. The sealed compare gate validates the export.

I1T exports existing computational checks, not a new independent replay. It reads the pinned route-A sidecar finish, every completed iteration's current/next I1T, and every executed driver tail stage's finish.json. Composite checks use the maximum of all parts. Every leaf requires exactly4096 samples, rtol1e-12, finite nonnegative max_rel and consistent PASS/FAIL. Missing, synthetic, wrong-size or partial records refuse; they are not filled. The run's full execution graph and validity remain the sealed compare's responsibility. The existing Codex2 computational implementation current_source_evidence_cx2v004.compute_i1t was inspected; it can independently replay an explicit own-call descriptor. This exporter preserves the actual runtime checks instead of silently asserting that independent replay occurred.

FLAG_RULINGS additionally requires `root_rulings` pointing to the root-written request conforming to FLAG_RULINGS_REQUEST_SCHEMA_V001.json. It validates all fields, case/result bindings, duplicate semantic keys and the sealed gate's flag/disposition rules, then writes ROOT_RULINGS. It creates no decisions, reasons or evidence. The authority field is a declaration in the root-written input, not cryptographic proof of authorship. Admission and root publication remain the authorization boundary. No actual ruling is included in this build.

`srb_rot_record_cx1v008.py MANIFEST OUTPUT` requires exactly `result`, `reconstruction`, `EPS`, each a byte reference. The result is the C4T output. The reconstruction is the existing Codex2 DDO154_STATE_REPLAY_DESCRIPTOR_CX2V001, operation rebuild, bound to the final rotation finish.json's uv_tail/state_digest. The descriptor and its source/recipe/context must already be prepared with actual saved-source custody; this writer does not invent them. It executes the pinned existing static reconstruction and verifies the final state digest and own-run normalized configuration. It currently accepts production P128/MS128 continuum, lambda1, cube K4 only.

SRB uses every EPS shell's eps_envelope and requires the registered envelope rule, contiguous coverage, dominance over actual-set epsilon and reach through sqrt(2)*128. It uses the library's static-channel arithmetic. Saved rotation arrays provide global sampled positive N_min and, conservatively, the minimum positive speed over vertical nodes for each column. Registered row radii select their exact one/two interpolation columns; the row bound is their maximum and receives the binding's inclination ratio. No observed velocities are opened. The array reader rejects duplicate/extensionless NPZ members and malformed or duplicate NPY headers. EPS remains a sampled estimate; this is the specified static necessary bound, not a fixed-point sufficiency claim.

TESTED:31 arithmetic/refusal cases;12 actual MT/I1T/FLAG main checks on synthetic trees;8 SRB checks using synthetic rotation arrays, explicitly stubbed reconstruction, actual library arithmetic and actual r11 gate;2 actual unsealed import refusals. First SRB main test failed because a generic path heuristic mistook prose in pinned prereg JSON for a filename. Final wrappers revalidate admission on every entry and check paths at explicit I/O boundaries; they never stamp or mutate parsed source records. Failure evidence remains immutable.

UNTESTED: full production replay/export, actual root seal, r6-state reconstruction, full gate registry acceptance by the eventual sealed compare.
