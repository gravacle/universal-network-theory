## 4. Identities, by hand

- **Static limit.** F_σ(0) = 2Σ w/D³ = 2·r3. Since K + σV = H(2+σ) − e2, the product eigenbasis of H(2+σ)⊗H(2+σ) diagonalizes M_σ with eigenvalues D_ab, and w_ab = |⟨u_a u_b|χχ⟩|². So h²·Δ_A·Δ_B·F(0) is the existing contact 2h²·Σ(ΔO)²·r3 at assembly L311 and in the review's "static_limit". ✓
- **Taylor truncation.** For |z| < D, 1/[D(D² − z²)] = Σ_n z^{2n}·D^{−(2n+3)}, so F = 2Σ_n z^{2n}·r_{2n+3}. The terms n = 0, 1, 2 give F4. ✓
- **Remainder.** The tail per (a,b) is z⁶·D⁻⁹/(1 − z²/D²). Two facts bound it:
  - |1 − z²/D²| ≥ 1 − |z|²/D² > 0;
  - x ↦ 1/(x⁹ − |z|²·x⁷) decreases for x² > |z|², because its derivative has the sign of −x⁶(9x² − 7|z|²).

  Hence |F − F4| ≤ Σw · 2|z|⁶/[m⁹(1 − |z|²/m²)]. The bound as coded omits the Σw factor, exactly as 0392 does, so it can understate the true bound by a relative amount of at most resid_tol (F3). ✓
- **Spectra are simple.** The H(d) graph is the path A0–B0–B1–A1 with nonzero couplings κ, g, κ, so every H(d) has a simple spectrum. q, w and D are therefore basis-unique up to phase, and q is phase-independent.

## Author open points: assessment

4. **Strict domain; one bad z fails the whole call.** This is 0392's "for every supplied z" plus fail-closed behaviour, and it is correct. A driver wanting partial results must split its z sets.
5. **Denominator summation order.** Accepted (§3).
6. **r_2 unused.** 0392 requires it to be reported, so this is correct.
7. **Graph factor not applied.** Correct.
8. **Carry-overs (eigh thread pinning, tolerance forms and units).** These are inherited from the 0384/0385 reviews, with no new concern.
