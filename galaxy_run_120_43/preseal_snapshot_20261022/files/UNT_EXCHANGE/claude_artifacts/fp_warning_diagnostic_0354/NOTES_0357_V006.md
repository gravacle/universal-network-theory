## Root's finding (0357)

V005 checked that the BLAS product was finite. It did not require the reference, the bound or the deviation to be finite before assigning the verified label. In floating point, `inf <= inf` is true, so a reference or |A||B| bound that overflows under cancellation made the check vacuous.

The finding is reproduced. E12a shows the natural case. E12d shows why it is silent: the non-BLAS `einsum` overflows to inf without raising even under `errstate(all='raise')`. It does not check the floating-point status, just like `np.dot`.

## Change in V006: `mm()` and `flag_report()` only

The returned array is still the unchanged `A @ B`. Numerical formulas, cases, tolerances and warning/flag reporting are all unchanged.

1. **Fail-closed gate.** A flagged, finite product is bound-evaluated only if all four of these are finite:
   - the inputs A and B;
   - the reference `_reference(A, B)`, a non-BLAS einsum;
   - the bound 64·k·eps·(|A||B|) + 64·k·smallest_subnormal;
   - the deviation |out − ref|.

   Otherwise the product counts toward `verification_nonfinite_products`, the bound is not evaluated, and the site is NOT_VERIFIED.
2. **D1 closure (delta-review note).** A non-finite product that raised no flag is recorded as `unflagged_nonfinite_products` (also counted in `nonfinite_products`) and is NOT_VERIFIED. Every call now checks the product for finiteness, and an unflagged finite product returns immediately, as before.
3. **Visible verification events.** Verification operations run under their own local `errstate(all='call')`. Any floating-point event NumPy reports there is recorded per site in `verification_fp_kinds`, kept separate from the backend product flags. These events are not converted into silent success. The einsum's internal overflow is not reported by NumPy, which is why item 1 is the gate.
4. **Label rule.** Verified means:
   - `nonfinite_products == 0`;
   - `verification_nonfinite_products == 0`;
   - `bound_failed_products == 0`;
   - `bound_evaluated_products == calls_with_flags`.

   Supporting fields:
   - `all_within_nonblas_bound` is null whenever any product was not bound-evaluated.
   - The maximum deviation now covers evaluated products only.
   - The NOT_VERIFIED meaning text lists every cause.
5. **Counter invariant.** calls_with_flags + unflagged_nonfinite = nonfinite + verification_nonfinite + bound_evaluated.
6. **TEST-ONLY injection point.** `_reference()` is a named helper so that a test can inject a non-finite reference. This file never alters it.
