## Caveat (preserved, required by 0454)

The projection is complex-linear in the supplied gradient coefficient. The surrounding density -> real field -> positive-mode chain is generally only real-linear, because it involves both signs and complex conjugates. This review therefore does not certify complex-linearity of the coupled operator.

The virtual-work identity shows exactly how the complex projection enters the real work. W_real = 4 pi Re(y^H delta_b s): the factor 2 comes from the complex-conjugate pair of the real fields, and the 2 pi from the angle integral. Neither factor belongs inside delta_b.

## Notes (non-blocking)

1. Integer-dtype inputs with |v| > 2^53 are rounded when cast to complex128 or float64, although the docstring (L35-36) says "losslessly". This is the same pattern as 0447 P53. It has no effect on root's float64/complex128 inputs.
2. Only when n = 3 would a transposed (3, n) grad be indistinguishable from (n, 3). Root's n = 2304.
3. The component loads sum to delta_b only up to rounding order, as documented. delta_b itself is the 0439-bitwise quantity.
4. Not reviewed: root's F2 iteration design (total RHS = b0 + delta_b, no accumulation of old increments), the FFT/16 extraction in root code and the induced-field computation. They are outside this operation.
