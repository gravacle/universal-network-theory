The writer snapshots every source/input path once, verifies its byte pin, and uses that same buffer for parsing, producer replay and output derivation. Canonical and original symlink alias keys both map to the same verified snapshot. Duplicate keys, nonfinite floats, unexpected fields and forbidden target/protected paths refuse. Target-field scanning occurs recursively before following record references; lexical protected-path checks precede metadata probes. Input size is at most2MiB per file. These source/text slots are root-reviewed metadata, not arbitrary datasets.
