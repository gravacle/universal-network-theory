## Interface interpretations (choices made)

1. Direction vectors for hull vertices are not in the `explore_region` output; the function accepts (a) the `run_calibration_region` output (`{'exploration': ..., 'identifiability': ...}`), (b) an `explore_region` dict carrying an `identifiability` dict (`right_vectors`, `identified`), or (c) top-level `right_vectors`. If `identified` is absent the identified directions are the `hull_box` keys (int or string keys). `hull_box` keys and `identified` must agree or the call refuses. `hull_box` values are only cross-checked (range tolerance 1e-6); a mismatch is reported as a WARNING reason with `hull_box_consistent=False`, not a refusal.
2. The anchor is included only if `anchor.admitted is True` (envelopes cover admitted points only); it is matched to an admitted point by `log_index` if present, else by exact `u` equality; an admitted anchor absent from `admitted_points` refuses.
3. Per-query validity: a point contributes a value for query q iff its `valid` flag is True and its value for q is a finite real; a query is valid iff at least one point was evaluated and every evaluated point contributed. An exception or a non-dict return contributes nothing, so it invalidates every query. A point with one NaN invalidates only that query (its other values are used); its point-level `valid` is False.
4. An invalid envelope with `n_valid >= 1` is written with its finite central/band and `valid: False`; the scorer still reports residual/sigma_ratio for it but never counts it within error. An envelope with `n_valid == 0` is written with `null` velocity/bands.
5. `write_freeze_manifest` hard-codes 43 query ids; `evaluate_envelopes` accepts any non-empty unique id list. `alternatives` and `observation_rule` may be dict, list or string; `notes` any JSON-native value. Integer dict keys (e.g. `hull_box`) become strings before hashing so the self-hash is stable under a JSON round trip.
6. Extra output keys beyond the interface minimum: `select_representative_points` adds `anchor_included, n_admitted, identified_directions, hull_directions, hull_box_consistent`; `evaluate_envelopes` adds `points_total, points_evaluated`; `verify_freeze_manifest` adds `path, canonical_bytes_match`; `load_query_manifest` adds `path`.
