## Interpretations of the interface (where the text left a choice)

1. **Spec field shapes.** `roles, transforms, lower, upper, trial_values` are dicts keyed by coordinate name (same style as the region's `rectangles`/`sigmas`). Extra helper keys: `free_names, varying_index, n_total, n_varying`.
2. **`theta_internal`** is the list of internal coordinates `x` over *all* coordinates in `spec.names` order (fixed coordinates included); `u` is over varying coordinates only.
3. **`admitted` for an invalid evaluation is `None`** (`bool|None` in the log shape); it is `True/False` only when the evaluation is valid. Invalid never counts as admitted anywhere (`admitted is True` is the only admission test used).
4. **`boundary`, `boundary_detail`, `hull_box` are keyed by the integer direction index** (literal reading of `{direction_index: ...}`); `json.dumps` turns them into string keys. Keys are present for every identified direction from the start of the exploration; a side that was never determined (budget exhaustion, or no admitted point) is `None`.
5. **Seed reuse.** `run_calibration_region` passes the seed evaluation to the exploration as the anchor, so the same point is not evaluated twice (the forward is minutes per call). Standalone `explore_region` evaluates its anchor itself with `purpose='seed'`.
6. **March at the box edge.** When the next doubling point would leave the box, the box-edge point itself (`t = t_edge`) is evaluated once if it lies beyond the last admitted `t`: if admitted, the boundary is the box edge as the interface says (`hit_box_edge=True`, `first_rejected_t=None`); if rejected, bisection runs between the last admitted `t` and `t_edge`. Costs at most one call per side and makes the recorded box-edge boundary a verified admitted point.
7. **Jacobian at a box face.** A side whose clipped step is zero (seed on a face) reuses `f0` without a call, so the column is one-sided there (`steps_detail[j]['one_sided']=True`). Halving re-evaluates both sides at the halved step.
8. **Repair details.** Pseudo-inverse restricted to identified directions `S⁺_I = Σ_k v_k (S v_k)ᵀ / s_k²` built from the report's own right vectors and singular values (fixed seed Jacobian, never re-evaluated). Target is the rectangle centres in sigma units. Step clipped to `max_repair_step` in u-norm, projected into `[0,1]^n`. If a repair evaluation is **invalid**, the next iteration retries from the last valid point with the cap halved; a valid-but-not-admitted point becomes the new current point. A step with no displacement (already at the linearised optimum, or fully clipped) stops the repair early. Every evaluation counts as one iteration. `NO_ADMITTED_POINT` + `empty_region=True` means no admitted point was found by this budgeted procedure (DDO154 rows only), not a proof of emptiness.
9. **Halton.** Bases are the first `m` primes for `m` identified directions; the first index is `rng_seed + 1` (index 0 is the degenerate all-zero point). With `m == 0` the design is skipped with a reason.
10. **SVD determinism.** Each right vector is sign-fixed so its largest-magnitude component is positive. When `n > 12`, singular values are padded with zeros to length `n` so `identified ∪ near_null = range(n)`.
11. **Extra statuses.** Besides `COMPLETE | BUDGET_EXHAUSTED | NO_ADMITTED_POINT`: `run_calibration_region` returns `INPUT_INVALID`, `SEED_INVALID`, `JACOBIAN_INCOMPLETE` (a failed column makes the identifiability report `ok=False`, so exploration is not run), `JACOBIAN_FAILED`, `EXPLORATION_FAILED`; `explore_region` returns `ANCHOR_INVALID` when the anchor evaluation is invalid and there is no valid point to repair from.
12. **`ok` semantics.** `ok=True` when the procedure ran to its designed end (`COMPLETE`, and `NO_ADMITTED_POINT` which is a legitimate registered outcome); `ok=False` for bad input, invalid seed, incomplete Jacobian and `BUDGET_EXHAUSTED` (partial results are still fully populated).
13. **`unidentified_directions[i]`** carries `index, vector_u, singular_value, trial_projection = u_anchor·v, admitted_anchor_projection = a·v, sensitivity = ||scaled_jacobian·v||`. `identified_directions` is reported in the same shape.
14. Unit coordinates are accepted within `1e-12` of `[0,1]` and clipped; `to_unit` tolerates `1e-9` rounding at the box faces. `trial_value` must lie inside the bounds.
