## Procedure (all tiers)
**Copy tool: `ditto`, via the existing `claude_artifacts/storage_move_c2/move_to_external1_v001.py`.**
- `cp -c` does not apply. clonefile() only works inside one APFS volume. Across volumes it fails or falls back to a plain copy.
- `/usr/bin/rsync` on this machine is openrsync (protocol 29, "2.6.9 compatible"). Its xattr/ACL (-E) coverage is not something to rely on. `--checksum` also adds nothing to a first copy into an empty destination, because it reads everything twice before copying.
- `ditto` is Apple-native. It preserves xattrs, ACLs, resource forks, symlinks and mtimes.
- Integrity comes from a separate per-file sha256 pass over source and destination, not from the copier.

Per directory, one at a time, under `nice -n 10`:
1. Preconditions: the source is a real directory, the destination is absent, External1 is mounted, `lsof +D` is empty, and there have been no writes for 600 s. For T1B and T2 also: no process has cwd under the UNT repo (`lsof -d cwd | grep 'Universal Network Theory'`).
2. Build the source manifest (relative path, type, size, mtime_ns, link target).
3. `ditto SRC DST`, where DST is the same relative path under /Volumes/External1/Research.
4. Verify:
   - same entry set;
   - type, size and link target for every entry;
   - sha256 of every regular file, source against destination.
   - Write `DST.SHA256_MANIFEST.json`.
5. Re-check the source manifest against step 2 and confirm `lsof` is still empty. If either fails, abort with the source untouched.
6. Swap:
   - `mv SRC SRC.__moved_to_external1__` (same volume, atomic);
   - `ln -s DST SRC` (absolute target);
   - read back 3 sampled files through the symlink and check them against the manifest.
   - If the swap fails, the tool automatically removes the symlink and renames the held copy back.
7. Delete the held internal copy. This is the only step that frees space, and it is a permanent delete. The existing tool does it automatically with `rm -rf` (line 134), so either run a variant that stops after step 6, or get the user's explicit go-ahead per batch before running it.

Extra checks:
- Tier 1A: run `--dry` on every path first. After the first KNOWLEDGE batch, check `df` against the manifest's byte total.
- Tier 2B (.git): run on a quiesced repo only, after the scratch-repo test. Expect hours of runtime (245k loose objects plus 70 GiB of packs). Do the final ref and mtime re-check immediately before step 6.

**Rollback**
- Before step 7: `rm SRC` (removes the symlink only; no trailing slash), then `mv SRC.__moved_to_external1__ SRC`.
- After step 7: `rm SRC`, then `ditto DST SRC`, then re-verify against `DST.SHA256_MANIFEST.json`.

**Cross-cutting hazards**
- External1 must stay mounted. Every symlink is absolute and dangles when the drive is unmounted.
- Walks of parent directories (BSD find without -L, os.walk, rglob, du) silently skip moved subdirectories. Inventories will under-report.
- Codex sandboxes cannot write into moved directories. This only matters for T2B .git.
