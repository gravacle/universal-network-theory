## 4. Notes (non-blocking)

- **N1. Overflow in the residual report.** A finite but huge returned residual (probe: 1e200) overflows `F.real**2` under the module's raising errstate. The wrapper then returns ok=False at stage `euler_residual_report`, with `action_result` preserved. It is fail-closed and never returns a non-finite value, but INTERFACE §4 does not document it. A scaled norm would avoid it.
- **N2. Odd nphi.** `_mesh_layout` requires only nphi > 12, not that nphi be even. An odd non-root mesh (probe: nphi = 13) passes assembly, so `evaluate_action` is called. The report then raises on an empty omitted-slot max and returns `internal` with ok=False. Root's `make_mesh` rejects odd n_phi (root L57), so this cannot happen on the real path. Requiring an even nphi before the call would close it.
- **N3. m0 AND test.** The AND test is mandated by the task. Its consequence is that a legitimately zero m=0 candidate carrying roundoff imaginary parts is rejected whatever `imag_atol` is, because the relative leg is 0 ≤ rtol·0. The relative leg also uses the global max|Re| over all three components, not each component's own (fact 7). Root should choose tolerances knowing both facts.
- **N4. Adapter keys Root must add.** `'m'` and `'solve_failed'` are not named by 0431 and are required explicitly (facts 1 and 2). Actual solver outputs without them fail closed until Root's adapter adds them. Component order (R, phi, z), physical z and the nodal meaning of the columns are also assumed (facts 3–5). Neither the conjugate sign nor eta-major flattening of the inputs is detectable from data, and both change the field silently (my contrasts confirm this). These must be confirmed against the producer.
- **N5. Module identity.** The binding is identified by signature only and the action by `MODULE_TAG` only, with no byte hashes (documented). The `constraint_rows` loss path inside root is described accurately (root L206).
- **N6. Cosmetic.** INTERFACE cites the reconstruction as L223-232; the code spans L223-233.
- **N7. No completion/ACK.** 0431 also asks for a completion/ACK reply in FROM_CLAUDE2. Neither the author nor this checker wrote one, because both runs were limited to the artifact folder and the scratchpad.
