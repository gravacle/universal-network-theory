## Notes (non-blocking)

1. **Validation stage moved for some inputs.** One-mode behaviour differs from 0449 only at the input boundary. A malformed rho dtype, shape or finiteness is now rejected at `validation`, where 0449 rejected it at `density_fourier_validation`; both are INVALID_INPUT. The roster (R, z, weights) is still validated only by 0445. A bad roster therefore gives INVALID_INPUT at `density_fourier_validation`, with `failure_mode` = the lowest m and that mode's 0445 dict retained.
2. **Common roster and wave order are guaranteed by construction, not by echo.** The module snapshots only `waves`. The roster objects are passed unchanged to every call, and the pinned 0445 copies them (`np.array(copy=True)`), so it cannot alter the roster between modes. 0445 does not echo wavevectors, so a non-pinned callable that reorders internally would be caught only by `counts.waves`. Callable identity rests on root's `provenance`, as in REVIEW_0449 note 5.
3. **Which arrays to consume.** In a COMPLETE result, `density_fourier_results[m]` holds the 0445-owned dicts, which are writable. `deltaJ0_J_by_mode[m]` and `deltaJ0_J_total` are read-only copies, and root should consume those.
4. **Summation is uncompensated.** It is plain IEEE in ascending m, as stated. Under strong cancellation between modes, the relative error of the total grows as |total| / max|deltaJ0_m| shrinks. That is roundoff, not a defect.
5. **REVIEW_0449 notes 1-9 still apply,** because the source-to-field stage is byte-identical. In particular, with `include_log_difference=True` a log positivity failure withholds the linear payload, so root should pass `False` for physical iteration. Also, the coefficient convention must be c_m with ρ = c_m e^{imφ} + c.c., not 2c_m; root must confirm this for its solved annular modes.
6. **Production cost is UNTESTED.** The deciding test is root timing one radius at production nk with all retained modes. The line-stage cost is independent of M (measured above); the 0445 cost scales with M.
7. **Interface accuracy.** The verbatim ranges, diff counts, signature, metadata keys and failure table in `INTERFACE_0452_V001.md` match the installed bytes. Its limitation 8 ("not reviewed yet") is superseded by this review. The interface file was not modified.
