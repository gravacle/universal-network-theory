## Independent check (ii): does interior_count = 5 change nothing beyond envelope breadth?

**The claim is not supported as stated. It is a NOTE (N1), not BLOCKING.** The value is declared before any result, and every dependence below runs through frozen rules.

What the count does and does not move:
- **Members.** `_selection_plan` takes the hull members, then the anchor, then the centroid-nearest admitted point (L1142), and only then the interior points. The centroid-nearest member is therefore present whatever the count is.
- **Tiers.** REFERENCE_RULE picks the nearest member that is both evaluated and valid (L2213-2222). Tiers, E3 and twins (r3a I-3 L76-78, L518) therefore do not depend on the count while that centroid-nearest member is evaluated and valid. Otherwise:
  - the reference can move to an interior member;
  - that happens on honest records when the call at that theta fails twice (rule (c)).
- **Headline.** min/median/max over every member, and n_members (L4229-4243), move whenever there are more admitted points than hull + anchor + centroid. For example, in Phase 1's 7-call branch with m_id = 1, the count gives 7 members instead of 4. In the 22-call branch it allows up to 12 members.
- **Envelope.** A row is valid only if no member is unevaluated (L2087). One unevaluated member therefore voids every row, and NEAR reads NOT_AVAILABLE on all 43 rows (r3a L152). That is validity, not breadth.
- **AT-1.** The test runs over every valid Phase-2 PRIMARY member (A133 L257), so the count can flip COVERED to SUPERSEDED, which withdraws the Phase-1 readings (L266).
- **Not moved:** the sensitivity column, which is never a reading (r3a L175), and the L1 band, which comes from u_A and F only.
