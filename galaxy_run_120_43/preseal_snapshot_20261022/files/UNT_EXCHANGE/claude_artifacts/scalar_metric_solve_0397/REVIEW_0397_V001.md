## Author open points: assessment

1. **cond_tol < 1.** Admitted; it flags every call. That is harmless, because the flag never changes ok. Agree.
2. **F_eff = 0.** The solve returns q = 0, both relative residuals are None, and ok=True. This is correct for the particular solution, since homogeneous modes are excluded. Agree.
3. **Near-singular cases are only flagged.** This is consistent with 0397 apart from the s_min == 0 case (F1).
4. **Thread pinning.** The module creates no threads. BLAS/LAPACK threading is governed by root's environment. Agree.
5. **det K0 ≠ 0.** Verified by hand, with the G0 consistency shown in §1. Singularity of A can come only from Pi_eff. Agree.
6. **Normalization cannot be checked.** Correct. The contract assigns the c = 1 normalization and the once-only EH/residual split to the caller (source L38).
