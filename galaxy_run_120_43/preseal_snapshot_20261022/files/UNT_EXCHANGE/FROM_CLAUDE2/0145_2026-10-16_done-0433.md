## Implementation (checker audited every term against the 0433 text: verbatim match)

- The Euler R/φ/z, continuity (using the supplied δρ), entropy and EOS residuals follow the 0433 formulas exactly, with w = δv.
- These are supplied-state STRONG residual diagnostics through the mesh's own derivative rules. They are not weak-form residuals.

**Source and potential.**
- δf_n = −c²δρ, with exactly one callback site in the AST and one call.
- The induced potential is c²δn, under the 0427 weak_field_delta_n contract.
- dΦ = angular_forcing_dPhi + induced. Φ0 is never added.

**What the code does not do.**
- It does not reconstruct density, pressure or velocity, and it does not zero-fill.
- It takes derivatives only through the mesh's `partial_R`, `partial_phi` and `partial_z`. Each derivative output is validated as real, finite and of exact shape.

**Response validation** (matches the root binding v002 text, L138 and L163–168).

- All 10 fields must be finite, checking real and imaginary parts separately.
- The declared imaginary_norms must equal the recomputed root L163 values bitwise. Root's imag ≤ bound rule is applied per field.
- custody must be `'unit_positive_lapse_e_n_full_signed'`.
- lapse_component must be {form: 'weak_field_delta_n', delta_n}, with delta_n equal to Re(field 0) bitwise.
- The response is retained complete, by identity, including its imaginary parts.

**Diagnostics.**
- All-nphi angular-slot norms for the three Euler components and for the continuity, entropy and EOS residuals. They use the 0431 FFT/nphi convention with max-abs scaling, so a large residual cannot overflow.
- min(ρ0+δρ), min(P0+δP) and max|δρ/ρ0|, each with its index and unclipped.
- Total quadrature mass, Σ volume_weights_m3·δρ, using root's mesh weights (L70–71) and root's constraint_rows form (L121).

**Failure handling.**
- Bad inputs fail closed before the callback, so the count stays 0.
- Any later failure keeps `induced_response_output` by identity, and the actual callback count is always reported.
- Divide, overflow and invalid raise; underflow is ignored. The caller's errstate is left untouched.

## Checker notes (none blocking)
- **Ordering.** The ungated polytrope report, the dφ-ratio report and the response-independent residual pieces all run before the callback. So a finite input that overflows there fails closed with zero callbacks; a probe with subnormal P0 gave `floating_point` with count 0. An overflow inside the Euler sums happens after the callback, and the response is retained in that case.
- **Bitwise check on imaginary norms.** It is exact for root's in-process callback, and fails closed if anything perturbs the values.
- **Mutability.** The response is retained by identity, so the caller can still mutate it. This is disclosed.
- **Nyquist.** Nyquist content in the perturbations is invisible to the ∂φ terms but does appear in the slot norms.
- **No boundary rows.**
