## What V003 adds
**Signature.** The public signature is unchanged: the same 23 keyword-only arguments, with no defaults. Mode directions are new entry forms inside derivative_coordinates:
- `{id, kind:"lapse_direction", profile_id, cell_weights{cell: φ}}`
- `{id, kind:"source_direction", profile_id, cell_weights, label_weights{("whitened_R",i) | ("whitened_S",i,j), i≤j : c_f}}`

The coordinate key is (kind, id), and these entries can be mixed with the existing tuple coordinates. A run without mode directions is numerically identical to V002. It only gains three keys: modes=None, inputs.mode_directions=[] and conventions.mode_directions.

**Projection before storage.** No cell Hessian is built.
- Lapse directions use ρ = v_X/multiplier, with v_X taken from the operator's own endpoint-averaged energy_weights, and D_a = Σ d_X v_X.
- Source directions use D_a = −Σ φ c O, from the SAME adapted_moment_reads evaluation that enters H_c, with ρ = 0.
- Only the projected columns are stored. The contact is n_u×n_u, for example 20×20.

**Weights and blocks.**
- Signed weights carry no partition admission.
- The full joint cos/sin block is returned. There is no phase averaging, no isotropy assumption and no symmetrization.

**Outputs.**
- Extensive F_total gradient and Hessian: −⟨S⟩/β and −(Cov+⟨T⟩)/β.
- Score/contact moments and the error layout. F standard errors are included only when mixing passed.
- Profile/Gram metadata: S, Σφ, c1, the unit-pairing Gram and its largest normalized off-diagonal.
- Separately tracked uniform first and pair moments.
- No mode-norm division.

## Review
The reviewer's diff -u is byte-identical to DELTA: 41 hunks, 8 new definitions, 14 changed and none removed. The reviewer re-checked the estimator algebra by hand. Notes, none of which block:
- **N1.** The input form is richer than the spec's literal minimal API. It needs id, profile_id and cell_weights, and source directions are factorized as φ_α·c_f over the nine whitened fields.
- **N2 (Mandel).** c_f multiplies the tensor element S′_ij, so an off-diagonal Mandel direction needs c_f = √2. Passing 1 scales that column by 1/√2. This is documented in L21. Root should set c_f explicitly.
- **N3.** The Gram non-orthogonality flag has no tolerance, so it will usually fire on rounding residue from cos/sin profiles. It is informational only.
- **N4.** uniform_moments.n_cells uses context.energy_cells, while the sums run over the callback cells. These are equal by construction with the actual adapter, because it shares the registration object, and equality is enforced when source directions are present.
- **N5.** Results follow the extensive convention: S, c1 and Q_ext are returned, so root does a single division by S.
- **N6.** An alias that exposes only owner_restricted_channels now fails closed, as R1 intends.
- **N7.** The nine uniform columns join the mixing judgment, so they can suppress error bands in mode runs.
