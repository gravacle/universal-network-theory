## Change (smallest exact repair)
1. **Forward store.** Each graph-and-owner entry now keeps only a flat array('q') of each cut's four sorted edge codes, in V002 order (32 B per cut). It keeps no cutmask, children masks or target_edgeset.
2. **Reverse store.** The graph-level tests are unchanged. Each surviving pairing keeps only (pairs, root_other) as code tuples.
3. **Eligibility first.** All of these checks now run before any mask, target graph or key exists:
   - the donor-RR and newborn-Ready guards, hoisted per owner;
   - the forward census, taken as four shifts (inc>>c)&1;
   - the reverse checks: equal paired child bits and a census by shifts.
4. **Transient descriptors.** These are built only for eligible channels, using the V002 expressions.
5. **Bounded structural cache.** The new REQUIRED registration key max_cached_graphs takes a positive int; there is no default, and bool or values below 1 fail closed. It drives an LRU over per-graph structure, and an evicted graph is rebuilt exactly on its next use. The port-order and accessor-value caches are never evicted, so eviction never re-calls a caller function.
