## Callables
Both are pure Python. The only import is `math` (fsum, isfinite, pi). Arguments are keyword-only, all required, with no defaults:
- `annular_bernstein_sigma(*, s_edges, annular_means, boundary_controls, s_query)`
- `annular_bernstein_area_integral(*, s_edges, annular_means, boundary_controls, s_lo, s_hi)`

Results come back as fail-closed result dicts with ok, stage_reached, failures, inputs, middle_controls, units, domain and scope:
- `sigma` adds bin_rule, bin_index and sigma.
- The integral adds per_bin and area_integral.
- The value fields are None unless ok is true.

Domain handling:
- The domain is the closed interval [s0, sn]. Any query outside it rejects the whole call, and so do s_lo<s0, s_hi>sn and s_lo>s_hi. The kernel never returns zero for an outside query and never adds a tail.
- An internal edge s[k] is evaluated in bin k, and sn in bin n−1. At t=0 the value is exactly d[k], so the edge rule cannot change Σ.

Formulas:
- t = (s − s_i)/w_i, b_i = 3m_i − d_i − d_{i+1}, and Σ = d_i(1−t)² + 2b_i t(1−t) + d_{i+1}t².
- The area integral is π·w_i·[F(t_b) − F(t_a)] per bin, summed with fsum, where F(t) = d_i t(1−t)² + (3m_i − d_{i+1}) t²(1−t) + m_i t³.
- A whole bin gives exactly π·w_i·m_i.

## Notes (none block use)
1. **LOW (adversarial F1): underflow.** When coefficients are near the subnormal range, or t underflows near the left edge, Σ or a bin's area can return 0.0 or lose relative precision while ok is True. The docstring reports rounding as computed but does not say that ok=True does not certify precision at underflow scale. This is the same class as the 0397 range qualification.
2. **LOW, plausible (adversarial F2): very narrow integrals.** For an interval only a few ulps wide, F(t_b) − F(t_a) can round to 0.0 or a tiny negative value (about eps·m·w·π). Σ itself stays ≥ 0.
3. **INFO: −0.0 inputs** can come back as signed zeros.
4. **INFO: flush-to-zero.** Division safety assumes IEEE gradual underflow. A process with flush-to-zero enabled could get w=0 from a subnormal edge width. Optional hardening is to require the computed s[j+1]−s[j] > 0.0 at admission; this was not applied, since no V002 was requested.
5. **INFO: stricter typing.** numpy scalars, Decimal/Fraction, sequence subclasses, ints that cannot be represented exactly and m above max/3 are all rejected (ok False). This is stricter than the spec, but fails closed.
6. **INFO, applicability (formula N2, adversarial F6).** The kernel cannot tell annular means from stellar medians or nodal samples. Applicability rests on the caller's declaration, through the argument name and scope text.
7. **INFO: rounding agreement.** The integral uses 3m−d_{i+1} rather than the returned b, so the Σ path and the integral path agree only to rounding. As a result, whole-bin means are exact.
8. **INFO: docstring wording (formula N1).** L25–26 runs ∫Σ ds and π∫Σ ds together in one sentence. The code (L403) and the usage note are consistent.
