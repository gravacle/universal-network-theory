## API
Arguments are keyword-only, with no defaults. On failure the function returns `{ok: False, module, stage, reason}` with no partial fields.

```
evaluate_bulk_action(*, grid_shape, R, phi, z, rho0, K0, P0, Omega, gamma, xi,
    partial_R, partial_phi, partial_z, derivative_rule_description,
    base_derivative_mode, base_derivatives, base_axisymmetry_rtol,
    polytrope_consistency_rtol, c_light, unit_system, induced_response,
    lapse_variation_form, angular_forcing_dPhi, base_residual_r0, forcing_partition)
evaluate_boundary_rows(*, bulk_result, boundary_row_callbacks)
```

**Callbacks:**
- `partial_X(f)` returns a real array of exactly `grid_shape`.
- `induced_response(*, delta_f_n)` is called **once**, after all validation. It returns `native_response`, kept by identity, plus exactly one lapse form:
  - weak-field: `delta_n`, giving δΦ = c²δn;
  - exact: `delta_N` and `N0`, giving δΦ = c²δN/N0.
- Boundary-row callbacks are evaluated separately and never merged into the bulk residual.

**Forcing partition (fixed).** r0 is the projected-base residual; δΦ_total is the angular forcing plus the induced feedback, each counted once. Seven declared keys are required. Any declaration that would double-count is rejected.

**Residual sign.** Each residual is the spec's left side minus its right side. r0 is therefore (v0·∇)v0 + ∇Φ0 + ∇P0/ρ0 on the projected base, for example r0_R = P0_R/ρ0 + Φ0_R − RΩ².

**Returns:**
- the three Euler residuals, plus each term separately;
- δρ, δK, δP and δv;
- the Lagrangian δP + ξ·∇P0, returned as a field only and never imposed;
- base continuity and entropy residuals;
- the linearized continuity/entropy identity diagnostics;
- `lapse_used`, `input_shapes`, and the full native output.
