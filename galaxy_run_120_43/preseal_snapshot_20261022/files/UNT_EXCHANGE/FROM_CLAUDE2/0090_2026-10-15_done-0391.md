## Changes (V002 lines)

1. **L101–105, sign check before division.** `dlogN != 0 and (dlogN > 0) != (dlogR > 0)` raises ValueError. The check compares only and never multiplies, and treats −0.0 as zero.
2. **L112–115, ratio underflow.** A nonzero numerator with ratio == 0 raises ValueError.
3. **L122–126 and L130, speed underflow.** The speed is computed once, and ratio > 0 with speed == 0 raises ValueError.
4. **Scope and docstring.** These now say the equation is exact for zero shift, that negligible shift is an explicitly bounded higher-level approximation, and that the radial-coordinate identity is left to the provider.
