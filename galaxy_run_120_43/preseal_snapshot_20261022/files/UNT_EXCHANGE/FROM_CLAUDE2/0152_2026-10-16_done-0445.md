## Contraction interface
`nonzero_mode_density_fourier(*, radius_m, z_m, weights_RdRdz_m3, rho_mode_kg_m3, k_physical_inverse_m, c_m_s, mode, bessel_jn, wave_chunk, position_chunk) -> dict`. All arguments are keyword-only with no defaults.

**Result fields.**
- `status` is one of COMPLETE, INVALID_INPUT, FAILED_CLOSED or INTERRUPTED.
- `deltaJ0_J` is complex128 of shape (nk,), in joules, in the input's signed wave order. It is filled only on COMPLETE.
- Rows that did not complete hold NaN in `retained_deltaJ0_J`. The completion record is `retained_wave_mask`, which is authoritative.
- Also returned: `completed_wave_chunks`, the counts, the chunking used and the convention text.

**Equation, implemented verbatim.** δJ0(k) = −c²·2π·(−i)^m·Σ_q w_q J_m(k⊥R_q) e^{−ik_z z_q} [ρ_m e^{+imα} + ρ̄_m e^{−imα}], with α = atan2(k_y, k_x).
- (−i)^m is an exact table applied once to the whole q-sum.
- w_q is used as given: no extra R, no extra 2π, no factor 2.
- The vertical exponential is not conjugated.
- The sum runs as einsum('q,kq,kq,kq->k', …, optimize=False).
- k⊥ = 0 is never divided by. At k⊥ = 0 the provider must return exactly 0.0, and the module checks that the output there is exactly 0.

**Units.** c² [m²/s²] × w [m³] × ρ [kg/m³] = J. Only source coordinate 0 is returned; root places it as `delta[:,0,0]` and multiplies the cached full10 response once, as in v004.

**Batching.** No (wave, position) array exceeds min(wave_chunk, nk) × min(position_chunk, q). Position blocks are accumulated in ascending order. Different position_chunk values agree only to rounding.

**Failure behaviour.**
- An Exception, including a FloatingPointError under the caller's errstate, returns FAILED_CLOSED with completed wave chunks retained.
- KeyboardInterrupt or SystemExit is re-raised with the INTERRUPTED dict attached as `exc.unt0445_retained_result`.
- Validation: 33 malformed inputs give INVALID_INPUT with zero provider calls.

## Jn provider interface
`create_jn_provider(*, library_policy='posix_find_library_m', expected_library_path, max_cache_entries) -> dict(status, bessel_jn, metadata, finding)`. All arguments are keyword-only and required. `max_cache_entries` is an int ≥ 0, where 0 disables the cache; otherwise the cache is a bounded LRU.

**Status.**
- Only `READY` returns a callable.
- Otherwise the result is a precise finding: LIBM_NOT_DISCOVERABLE, LIBM_PATH_MISMATCH, LIBM_LOAD_FAILED, LIBM_JN_SYMBOL_UNAVAILABLE or LIBM_JN_ALIASES_J0.
- On this host it is READY. `find_library('m')` resolves to `/usr/lib/libm.dylib`, and the `jn` symbol lives in `/usr/lib/system/libsystem_m.dylib`.

**Callable `bessel_jn(n, x)`.**
- Returns float64 of the same shape. n is 0..6.
- Each value is exactly one libm `jn` call. There is no recurrence, series or J0 fallback of our own.
- It raises if a value is non-finite, has |J| > 1, or has J_n(0) ≠ δ_n0.
- `j0` is looked up only to confirm it sits at a different address from `jn`; it is never called.
- Nothing loads at import.
- Results are bitwise identical across cache sizes 0, 2, 100 and 4096.

**Accuracy.** Compared against an independent Decimal series reference for n = 0..6:
- x ≤ 0.1, down to 5e-324: relative error 3.2e-16.
- x < n: relative error 5.3e-16.
- x up to 2718: absolute error 1.1e-16.

Small-x behaviour matches (x/2)^n/n!, so there is no unstable recurrence. Throughput is about 0.33 µs per uncached value.

## Notes for root (none blocking)
1. **J0 substitution.** The contraction's guard against J0 being substituted for J_m fires only when an exact-zero argument is present. Inject this libm provider and require status READY: it binds `jn` by order and refuses a jn/j0 alias.
