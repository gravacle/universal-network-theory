## API
`project_density_map(*, value, partial_R, partial_z, weights, radius, rho, xi_R, xi_phi, xi_z, mode, provenance, rhs_batch_size)`. All arguments are required and keyword-only.
- Validation is the same as for the vector function, except that ξ_R, ξ_φ and ξ_z must be complex with identical shape (2304, nfree), nfree ≥ 1.
- `rhs_batch_size` is a positive int (bool rejected) and is never chosen silently.

**Equations.** These are the 0441 equations, unchanged. Every product uses `einsum(optimize=False)`; there is no BLAS and no warning suppression.
- M = VᴴWV is formed once, and its exact block-diagonal structure is checked.
- B = VRᴴ((Wρ)ξ_R) − i·mode·Vᴴ((Wρ/R)ξ_φ) + VZᴴ((Wρ)ξ_z).
- 72 independent 8×8 `linalg.solve` calls are made per batch, with multiple right-hand sides.
- G = V·coefficients.
- The direct residual is M·coefficients − B, with norms per (block, column) and per column.
- The mass integral dot(W, G[:,j]) is reported per column and is not forced to zero.
- There is no acceptance flag.

**Memory, measured on a full-size stub with nfree=64.**
- Fixed cost: about 10.6 MB for the W·V temporary during M assembly, 2.65 MB for M, and about 1.6 MB of masks. The assembly peak is 17.4 MB at every batch size.
- Per-batch temporaries: about 221 KB per batch column.
- Results: 65,112 B per column.
- Measured batch-loop memory: 0.56, 0.95, 2.82 and 6.07 MB for batch sizes 1, 4, 16 and 64.

**Failure statuses.**
- `failed_closed_solve`, `failed_closed_floating_point`, `interrupted` (KeyboardInterrupt) and `failed_closed_internal`.
- Each one keeps `failed_stage`, `failed_batch`, `failed_block`, the `completed_block_batch` (72 × n_batches) boolean, `completed_batches`, `n_completed_columns`, the mass blocks with their diagnostics, and a `partial_<key>` for each result array.

## Notes
- **N1 (being fixed in c2v002).** The batch's B is stored in `partial_B` and recorded in `B_assembled_batches` before its finite check. After a default-errstate overflow, `partial_B` for the failed batch can therefore hold non-finite values while that batch is listed as assembled. This contradicts the interface's "NaN unless completed and passed checks". It affects failure-path partial outputs only; successful results are unaffected. Until c2v002 is returned, treat `partial_B[:, failed batch]` as unvalidated.
- **N2.** KeyboardInterrupt is returned as `status: interrupted`, not re-raised, to retain work. Root's driver must check the status, or Ctrl-C will not end a loop over calls.
- **N3.** In single-statement interrupt windows the completion record under-reports, which is the safe direction. An interrupt during post-processing propagates and loses the dict. The window is narrow.
- **N4.** Diagnostics behave as in c2v002: a non-converged SVD gives NaN singular values, and a zero smallest singular value gives cond = inf. No threshold is applied.
- **Differences from the vector function.**
  - B is grouped as `(W·ρ)·ξ` per 0441, while the vector function computes `W·(ρ·ξ)`. B therefore differs from the vector function at rounding level only.
  - The map fails closed on a non-finite residual norm or mass integral, which is stricter than the vector function.
