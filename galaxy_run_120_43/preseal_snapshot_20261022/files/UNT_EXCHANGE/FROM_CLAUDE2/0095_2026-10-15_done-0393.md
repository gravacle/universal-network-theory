## Answers, with the corrections applied

### 1. What the 43 entries are

- The manifest binds them to the data rows of `sparc_official_NGC3198_rotmod.dat` and withholds the velocities.
- The CDS ReadMe defines Vobs at l.225 as "Observed circular velocity" (table2), in km/s.
- SPARC paper p.6 §3.2.2: "rotation velocities obtained from fitting separately the approaching and receding sides", and "Inclination corrections go as sin(i)".
- *C2:* "deprojected" is an **inference** from that sin(i) sentence. The paper never says the values are line-of-sight velocities divided by sin i, and it never uses the words "deproject" or "line of sight".

### 2. Where each convention is stated

- **Inclination.** ReadMe l.153 plus Note (3) at l.200–206, and paper p.2: tilted-ring fit including warps, mean i taken in the outer HI disk, in some cases fixed to the optical value.
- **Distance.** ReadMe l.223, "Assumed distance". The manifest's reference-distance entry agrees and states "No distance is chosen".
- **Beam.** Paper p.5 §3.2.1 covers beam smearing, and notes hybrid curves (Hα inside, HI outside).
- **Non-circular motions.** Treated as random error (p.6; ReadMe Note (1) at l.233). Inclination systematics are excluded from the errors (l.234).
- **Warp.** Covered only by the conditional statement on p.6.
- **Pressure support.** Paper p.1: significant only in very-low-mass galaxies. The paper never uses the phrase "asymmetric drift".

### 4. Can the existing metadata bind the definition? Partly. Specific missing fields

- **M1 (narrowed by C1).** The unit of the rotmod velocity column. Only the units-line first token (kpc) was ever asserted.
- **M2.** The NGC3198 table1 Ref field, bytes 117–130, beyond the bytes 1–41 read in 0349. *C4:* Ref identifies the publications that document ring widths, beam, i(R)/PA(R) and the warp model. It does not fix those values itself.
- **M3.** The NGC3198 "Qual" flag (CDS label; "Q" in the paper), bytes 113–115.
- **M4.** Whether the curve is a hybrid of Hα and HI.
- **M5.** Whether each point was deprojected with the mean i or the ring-by-ring i(R).
- **M6.** A rule for rescaling radii with distance. The paper's only "rescaled" refers to M/L, not radii.
- **M7.** Whether pressure support or asymmetric drift was applied for NGC3198.
- **M8.** Per-point ring width, and any rejection of inner points.
