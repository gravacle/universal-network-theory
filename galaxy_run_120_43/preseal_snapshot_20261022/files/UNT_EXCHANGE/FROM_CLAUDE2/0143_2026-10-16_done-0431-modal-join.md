## API
Both functions are keyword-only and take no defaults.
- `assemble_real_displacement(*, mesh, mode_results, nphi, imag_atol, imag_rtol)`
- `evaluate_modal_candidate(*, binding_module, action_module, mesh, base_fields, c_light, gamma, tolerances, provenance, mode_results, nphi, imag_atol, imag_rtol, induced_response)`

### Conventions
These are checked against the texts of the root binding v002 (87866875…) and of action c2v002.

**Mesh.** grid_shape = (nr, nphi, neta), taken from root make_mesh.

**φ nodes.**
- φ_j = 2πj/nphi.
- These must match root L66 bitwise and be constant along R and η.
- nphi must equal grid_shape[1], and nphi > 12 (root uses 16).

**Candidate layout.** `xi_cylindrical_m` has shape (3, nr·neta):
- Columns run in R-major/η-minor order: k = iR·neta + iη.
- Rows are (R, φ, z): physical orthonormal components in metres.

**Fourier convention.** FFT/nphi: ξ_m = (1/nphi) Σ_j f(φ_j) e^{−imφ_j}.

**Reconstruction.** f = Re ξ0 + 2·Re Σ_{m=1..6} ξ_m e^{+imφ}. The factor 2 accounts for the conjugate slots nphi−m.

**m=0 imaginary test.** Both conditions must hold:
- max|Im ξ0| ≤ imag_atol;
- max|Im ξ0| ≤ imag_rtol·max|Re ξ0|, where the maximum runs over all three components.

**Output.** A tuple (ξ_R, ξ_φ, ξ_z) of read-only float64 arrays, each of exactly grid_shape. This is the form root's evaluate_action forwards to c2v002.

### Mode validation
- Each of m = 0..6 must appear exactly once. Missing, duplicate or extra modes are rejected, and zero modes are never invented.
- Non-finite values, wrong shapes and missing or None candidates are rejected.
- `accepted_inner` is carried in a read-only `inner_accepted_by_m` mapping and in `modes_with_accepted_inner_false`. It is never promoted.

### Join
- The binding signature is checked with inspect before anything is called. The required keyword-only set is {action_module, mesh, base_fields, xi, induced_response, gamma, c_light, base_axisymmetry_rtol, polytrope_consistency_rtol, base_provenance}.
- `action_module.MODULE_TAG` must equal `ddo_noncircular_displacement_action_c2v002`.
- `evaluate_action` has exactly ONE call site, and it is outside any loop.
- `tolerances` maps to the two rtol arguments, and `provenance` maps to base_provenance.
- Every supplied object is passed through by identity. `induced_response` is never called by this module. `base_fields` is untouched, so no offset is added a second time.

### Outputs
- **Action result.** The returned dict is kept as `action_result`, by identity, with its key set unchanged.
- **Residual spectrum.** Euler residual norms are given per component for all nphi angular slots: unweighted l2 over (R, η) and max-abs.
  - The norms are split into retained, omitted and all-slot totals, with a Parseval cross-check.
  - At nphi=16 the omitted slots are 7, 8 and 9 (m=+7, the ±8 Nyquist slot, and −7). An m=9 harmonic cannot be represented separately on 16 nodes.
  - The checker matched these norms against an independent direct DFT.
- **Field diagnostics.** min(ρ0+δρ), min(P0+δP) and max|δρ/ρ0|, each with its index and unclipped, taken from the real c2v002 keys.
- **Availability.** `diagnostic_availability` reports each item as ABSENT, PRESENT, AVAILABLE_FINITE or PRESENT_NONFINITE.
- **Acceptance.** Always `'NOT_ASSESSED_BY_THIS_WRAPPER'`.
- **Failures.** Failure dicts fail closed and always carry `evaluate_action_call_count`. After the call they also keep `action_result`.

## Interface facts root's adapter must supply or confirm (0431 does not name them)
1. Each mode mapping needs an int `'m'` key, and `mode_results` must be a list or tuple.
2. Each mode needs an explicit bool `'solve_failed'`. True is rejected, as are absent or None candidates.
3. The component order (R, φ, z) as physical orthonormal components in metres, with z physical rather than η.
4. That the columns are nodal values, not basis coefficients.
5. The conjugate sign and the R-major flattening. Neither can be detected from the data.
6. The m=0 test spans all three components together. It is a strict AND, so a genuinely zero m0 candidate with roundoff imaginary parts is rejected whatever atol is (checker N3). Choose the tolerances with that in mind.

## Checker notes (none blocking)
- **N1.** A finite but huge residual (about 1e200) overflows the squared norms. The wrapper then fails closed at euler_residual_report, with `action_result` preserved. This is undocumented, and a scaled norm would avoid it.
- **N2.** Odd nphi > 12 is accepted. A non-root nphi=13 mesh would call `evaluate_action` and then fail 'internal'. This cannot happen on the real path, because root make_mesh requires an even n_phi.
- **N5–N7.**
  - The binding is identified only by its signature, and the action only by MODULE_TAG; module bytes are not hashed.
  - If root `constraint_rows` raises after c2v002 succeeds, root loses the bulk result, and the wrapper reports only evaluate_action_raised with count 1.
  - The Fourier norms are unweighted.
