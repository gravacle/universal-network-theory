## Explicit rank proof

Suppose, as an operator on that ENTIRE sector,

 a D+b S+c P_s−d Q_s+e Q_q+f S_g+g N = C I.

The coefficient letters here are test numbers, not native Bind g or the physical coordinate names. All comparisons below are diagonal basis-state differences, so the common C cancels.

1. Work at N=0 with all graph cells Ready, carriers p=0, donors RR and initially all q=0. This is admissible: each local Q_i=M_i=1 and hence the global constraints hold. Changing q at one site leaves all resources unchanged. With no occupied incidence edges that site has d_i=0, s_i=−2, so the relation gives e+2d=0. Repeat at an endpoint of one occupied supporting edge, with d_i=1,s_i=−1: e+d=0. Therefore d=e=0. Native q is an independent record bit in this sector; neither admission nor state reachability is assumed for this rank witness.

2. At the same N=0 states replace one site Ready/p0 by Spent/p1, holding its q fixed. This preserves its local Q_i=M_i=1 and global Nc=S_g. The change is c s_i+f. Degrees0 and1 therefore give −2c+f=0 and −c+f=0. Thus c=f=0. This uses allowed basis states, not an assertion p_i=Spent_i throughout the full sector.

3. With these four coefficients zero, compare incidence configurations at N=0 with all Ready/p0/q0 internals. From the all-empty incidence word, occupying ONE edge changes (D,S) by(−6,2): two vertices move s=−2 to−1. Occupying TWO distinct edges sharing one vertex instead changes (D,S) by(−10,4): the center moves from−2 to0 and two distinct neighbors from−2 to−1. Both words are in the full cube. Hence −6a+2b=0 and −10a+4b=0, forcing a=b=0.

4. The remaining relation is gN=C. Any N=0 basis state gives C=0. The explicit eligible four-cut loaded channel above has a retained N=1 image with newborn Ready/p=q0, old internals unchanged and that donor pair II. It satisfies the same total charges, so g=0. Its incidence need not be ice; complete complements are part of the domain.

Every test coefficient and the identity coefficient vanish. Therefore the seven diagonal coordinate operators are linearly independent modulo ONE global identity; together with identity their real operator span has dimension eight. The result is exact on the finite declared sector, with no statistical or numerical rank tolerance.

## What the count means and does not mean

The proof establishes seven independent uniform diagonal OPERATOR coordinates. It does not establish seven independently measured universal constants, seven additional fitted parameters, or a final total for UNT. The original-to-coordinate map, adopted relations, allowed profiles, state/preparation, observational identifiability and physical units remain separately accounted in C178. In particular r=0 is a diagnostic restriction, not an extra redundancy proved here.

Restriction changes rank: on strict ice, D=S=P_s=Q_s=0; at fixed N the nu term is also an identity. Imposing r=0 removes that coefficient from the chosen family. None of these restricted conclusions can be used to erase a full-domain owner while retaining arbitrary incidence and Birth sectors. Similarly, a global reference shift is not permission to subtract different constants at each N.

## Off-diagonal accounting kept separate

At fixed basis conventions the native owner types have distinct nonzero matrix-element supports: Bind changes one q at occupied p; admission changes a cell and its carrier; an incidence flip changes one edge bit; hopping changes two endpoint carriers at fixed cells/incidence; Birth changes supporting graph/active labels, donor pair and newborn factors. The full domain supplies examples of each nonzero support. Thus no diagonal linear combination absorbs one of these owners, and their elementary support distinction is not a reason to identify g with Gamma or one coupling with another.

This is NOT a completed gauge-quotient count. The prior C178 note supplies common admission and Birth rephasing conventions only with states/reads/controls transformed consistently. Hopping cycle phases and profile compatibility need their own treatment; real/imaginary coefficients in a fixed basis must not automatically be counted as physically separate fitted magnitudes. A common energy/time scale and physical read normalization likewise require correspondence. No new count for these categories is asserted here.
